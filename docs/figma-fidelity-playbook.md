# 260906 Figma 구현 검수 플레이북

이 문서는 실제 구현에서 발견된 오차를 재발 방지용 사례(few-shot)로 정리한 것이다. 구현 baseline은 회귀 감지용일 뿐 디자인 정답으로 사용하지 않는다.

## 기준 우선순위

1. Figma의 지정 프레임과 개별 노드의 크기·간격·원본 에셋
2. HWP·카드뉴스의 공식 문안
3. 사용자가 승인한 제품 보완 사항
   - 모바일 본문 전체의 소프트 그라데이션
   - sticky 헤더 아래에서 시작하는 모바일 코스 콘텐츠
   - PC 기준으로 통일한 선물 문안과 목록
   - `완주 인증 티셔츠`에는 최신 프레임의 물통이 아닌 기존 티셔츠 원본 아이콘 사용
4. 현재 구현 스크린샷은 변경 전후 회귀 비교에만 사용

## 실제 실패 사례와 적용 규칙

### 장식 에셋

- `ㄱㄴㄷㄹㅁ`, 종, 태극, 자전거처럼 방향성이 있는 장식은 Figma 노드의 회전·반전을 확인한다.
- PNG는 알파 채널의 존재만 보지 말고 실제 투명 픽셀(`alpha min = 0`)이 있는지 검사한다.
- 데스크톱 원본을 모바일에서 비율 축소하며, 흰 바탕이 합성된 모바일 캡처 이미지를 대신 사용하지 않는다.
- `width`와 `height`를 동시에 임의 변경하지 않는다. 원본 종횡비와 `object-fit: contain`을 유지한다.

### 선물 아이콘의 의미

- 파일명과 데이터 키만 확인하지 말고 실제 glyph가 항목의 의미와 일치하는지 육안으로 검수한다.
- `완주 인증 티셔츠`는 69×69 티셔츠 원본 벡터를 사용한다. 최신 Figma 프레임의 물통 아이콘은 승인된 제품 보완 사항과 충돌하므로 정답으로 사용하지 않는다.
- Figma fidelity에서는 이 한 아이콘의 픽셀 비교만 제외하고, 위치·크기와 제품 회귀 스크린샷으로 변경을 감시한다.

### 텍스트와 장식 레이어

- 장식이 글자와 겹칠 때 제목 부모를 독립 stacking context로 만들고, 제목 텍스트를 장식보다 명시적으로 앞에 둔다.
- DOM 작성 순서에 우연히 의존하지 않는다.
- 장식 위치는 화면 전체가 아니라 해당 제목 래퍼를 기준으로 지정한다.

### 타이포그래피와 버튼

- 폰트 크기만 맞추지 말고 family, weight, line-height, letter-spacing, 실제 줄바꿈을 함께 비교한다.
- 버튼은 시각 박스와 최소 44px 조작 영역을 분리한다.
- Figma에 없는 hover 이동, 그림자, 자동 애니메이션을 추가하지 않는다.

### 모바일 헤더와 콘텐츠

- Figma의 정적 프레임에서 겹쳐 보이지 않아도 실제 sticky 헤더는 별도 stacking context를 만든다.
- 장식의 화면상 시작점이 헤더 하단보다 아래인지 실제 브라우저 좌표로 검사한다.
- 첫 요소만 보정하지 않고 페이지 콘텐츠 흐름의 시작 간격을 조정해 후속 섹션과 푸터가 함께 이동하게 한다.

### 반응형 관계

- 1440px와 402px에서 Figma 기준값을 먼저 맞춘다.
- 중간 폭에서는 고정 `top`/`height`가 아니라 `aspect-ratio`, flex/grid 흐름, 요소 간 gap을 유지한다.
- 카드뉴스는 `정사각 카드 → PC 16px/모바일 9.6px → 도트` 관계가 카드 폭이 바뀌어도 유지되어야 한다.
- 전체 페이지 높이가 같다는 이유로 내부 오차를 승인하지 않는다.

### 카드뉴스 상호작용

- 마우스·펜·터치를 Pointer Events 하나로 처리한다.
- 드래그 중 트랙이 포인터를 따라와야 하며, 짧지만 명확한 수평 제스처도 동작해야 한다.
- 세로 제스처는 페이지 스크롤을 막거나 슬라이드를 변경하면 안 된다.
- 첫/마지막 슬라이드에서 순환하지 않고 저항만 표현한다.
- 도트, ArrowLeft/ArrowRight, Home/End, ARIA 현재 상태를 함께 유지한다.

## 완료 검증

- Figma fidelity: 1440px PC, 402px 모바일
- 제품 회귀: 1440px, 1024px, 402px
- 반응형 관계: 360/390/402/430/768/1024/1366/1440/1920px
- 제품 확인 캡처: 1920px PC, 430px 모바일
- 에셋: 깨진 참조, 투명 장식, 원본 비율
- 상호작용: 마우스 드래그, 짧은 모바일 스와이프, 모바일 세로 스크롤, 키보드, 비순환 경계
